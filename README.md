# Unlimited Wordle

A static, unlimited Wordle-style game.

**Live Demo:** https://wordle-but-unlimited.shameelm.workers.dev/

## Files
- `index.html` — page structure
- `style.css` — styling
- `script.js` — game logic and word list

## Run locally
Open `index.html` in a browser. No build step or dependencies are required.

## Publish
Upload the contents of this folder to a static host such as GitHub Pages or Cloudflare Pages. Keep all three source files in the same directory.

Game progress and statistics are stored in the browser's local storage; there is no account system or shared leaderboard.
